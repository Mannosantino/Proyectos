# Feria Sustentable

Sitio web académico para presentar una feria dedicada al consumo responsable y la sostenibilidad.

## Descripción

El proyecto reúne información sobre expositores, actividades, comunidad, gastronomía y contacto en una página de navegación simple.

## Funcionalidades

- Navegación por secciones
- Presentación de expositores
- Cronograma de actividades
- Información de comunidad y gastronomía
- Sección de contacto

## Tecnologías

- HTML5
- CSS3

## Cómo verlo

1. Clonar el repositorio.
2. Abrir `index.html` en un navegador.

## Contexto académico

Trabajo integrador grupal realizado en UADE para la materia Diseño y Desarrollo Web.
