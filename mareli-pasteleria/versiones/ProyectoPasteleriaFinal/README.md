# Marelí Pastelería Casera

Sitio web desarrollado para un emprendimiento real de pastelería artesanal de Villa del Parque, CABA.

## Descripción

La página presenta la identidad del negocio, su catálogo de productos, información para realizar pedidos y accesos directos a sus canales de contacto.

## Funcionalidades

- Presentación del emprendimiento y su propuesta
- Catálogo visual de productos
- Diseño adaptable mediante CSS Grid
- Enlaces a ubicación, Instagram y WhatsApp
- Interfaz en español orientada a clientes

## Tecnologías

- HTML5
- CSS3

## Cómo verlo

1. Clonar el repositorio.
2. Abrir `index.html` en un navegador.

No requiere instalación ni dependencias.

## Contexto

Proyecto realizado para un negocio real. El objetivo fue construir una presencia web clara y accesible para mostrar sus productos y facilitar el contacto con clientes.
